# Георгию: сравнение «наряд + фото → вердикт»

Пакет из трёх файлов:
- `expected_equipment.json` — таблица ожидаемой техники (источник истины от Татьяны).
- `verdict.py` — готовый модуль сравнения (без зависимостей).
- `README.md` — этот файл.

Задача: при загрузке фото сохранить `task_id`/`work_name`, посчитать детекцию **один раз**,
сравнить с таблицей и отдать статус в **приложение** и **дашборд**.

---

## 1. Имя файла = наряд + бригада

Приложение присылает файл вида `<...>_<наряд>_<бригада>.jpg`, напр. `1789_Бетонирование_Б-1.jpg`.

```python
from verdict import parse_filename
work, brigade = parse_filename("1789_Бетонирование_Б-1.jpg")  # ("Бетонирование", "Б-1")
```

## 2. Сравнение (один раз, при загрузке)

```python
from verdict import load_rules, parse_filename, verdict

rules = load_rules("expected_equipment.json")   # загрузить один раз при старте

work, brigade = parse_filename(file.filename)
result = verdict(work, detections, rules)       # detections из нейросети
# result = {"work":"Бетонирование","status":"confirmed",
#           "required":["mixer","crane_manipulator","autocran"],
#           "found":["mixer"],"detections":1}
```

**Статусы:**
| status | Когда | Что видит прораб / руководитель |
|---|---|---|
| `confirmed` | нашлась хотя бы одна требуемая техника (conf ≥ 0.5) | «Выполнено» |
| `not_confirmed` | детекции были, но не те | «Не обнаружено» |
| `review` | детекций нет совсем | «Переснять» |
| `unsure` | работа не найдена / низкая уверенность | «Не проверяется» |

## 3. Что хранить и что отдавать

Сохранить на диск/в БД вместе с фото:
```json
{ "file": "1789_Бетонирование_Б-1.jpg",
  "task_id": "Бетонирование", "work_name": "Бетонирование", "brigade": "Б-1",
  "detections": [{"class": "Mixer", "confidence": 0.89, "bbox": [742, 382, 344, 355]}],
  "status": "confirmed", "found": ["mixer"], "computed": true }
```

**`GET /photos`** — в каждый элемент списка положить статус (сейчас это пустое поле):
```json
{ "file": "1789_Бетонирование_Б-1.jpg",
  "work": "Бетонирование", "brigade": "Б-1",
  "status": "confirmed", "found": ["mixer"], "confidence": 0.89 }
```

**Приложению прораба** (по существующему контракту): для фото со статусом `review` → «переснять».

## 4. Зачем «считать один раз»

Сейчас нейросеть запускается при каждом запросе списка фото. Нужно посчитать при загрузке
и запомнить (`computed: true`) — тогда список отдаётся мгновенно, демо не ждёт.

## 5. Порядок для демо

Оставляем работы, где модель уверена: **Бетонирование** (mixer, crane_manipulator, autocran),
**Армирование** (bucket_loader_standard, dump_truck). **Двери убираем** — техники нет.
