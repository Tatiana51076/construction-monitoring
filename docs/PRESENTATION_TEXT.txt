ОБЪЕКТИВ — ТЕКСТ ДЛЯ ПРЕЗЕНТАЦИИ
(кратко, по сути, с нитью технической проработки)

«Объектив» — интеллектуальный мониторинг строительной площадки.

На стройке всегда есть два инструмента — календарный график и камеры. Но сверяет их человек вручную: смотрит кадры, звонит подрядчику, сверяет с таблицей. Это долго, а срыв срока замечают, когда он уже случился. «Объектив» делает эту сверку автоматически.

Как это работает технически. Камеры снимают площадку. Нейросеть YOLO распознаёт 17 классов техники: экскаваторы, самосвалы, краны, катки и другие. Чтобы один и тот же объект не посчитался несколько раз с разных камер, работает дедупликация — один объект считается один раз. По каждому рабочему дню система ставит уровень активности: работа идёт, только ресурсы, ничего не найдено или кадров нет. Дальше уровень дня сверяется с календарным планом по правилам R1–R8, и из этого складываются три независимые оси: наблюдение — что видела камера; отчётность — что заявил подрядчик; сроки — насколько сдвигается завершение. На выходе — отклонения, оценка риска и прогноз срока. Технологически это бэкенд на FastAPI с единым JSON API и базой данных.

Главный принцип — честность. Система не утверждает, что работа выполнена, — она фиксирует только то, что видела. То, чего камера не видит, честно помечается «не проверяется», а не красится в зелёный. Поэтому выводы системы обоснованы и справедливы.

Что видит руководитель. Портфель объектов, отсортированный по проблемности: сверху — самые проблемные. Внутри объекта — план и факт, календарь день–неделя–месяц, кадры, риск и методология: откуда взялся вердикт. Главный сценарий: подрядчик заявил 100 процентов, а камера техники не видела — система подсвечивает «ложное завершение», и это подтверждено кадром.

Отдельно — приложение прораба. Максимально простое: один тап — одно фото. Оно работает без интернета: фото копятся на телефоне и досылаются сами, когда появляется связь. Плюс соревнование бригад на объекте — это мотивация, а не надзиратель.

Итог. Срыв срока видим заранее, а не постфактум. Каждое отклонение подтверждено кадрами — меньше споров. Ручной работы меньше, решения объективнее, расчёты справедливее. Статус стройки руководитель понимает за тридцать секунд.

«Объектив» — это не камера, которая следит. Это система, которая видит стройку честно — и помогает не сорвать срок, а не искать виноватого. Ставьте камеры, дайте нам график — остальное сделаем мы.


КОРОТКАЯ ВЕРСИЯ (30 секунд)

На стройке есть график и камеры, а сверяет их человек вручную. «Объектив» делает это сам: нейросеть распознаёт технику на кадрах, система убирает дубли между камерами, по каждому дню ставит уровень активности и сверяет с планом и отчётом подрядчика. Руководитель видит три вещи раздельно — наблюдение, отчётность и сроки — с доказательством кадрами. Принцип честности: показываем только то, что видела камера, остальное честно помечаем. Плюс приложение прораба: один тап — фото, работает без связи, и соревнование бригад.


ТЕХНИЧЕСКАЯ НИТЬ (одним абзацем)

Камеры → детекция YOLO (17 классов техники и люди) → дедупликация между камерами (один объект = один) → уровень дня 0/1/2/null по каждой работе → правила сверки R1–R8 и пороги на работу → три оси (наблюдение / отчётность / сроки) → замечания с остротой и прогнозом срока → дашборд: бэкенд на FastAPI, единый JSON API, база данных, приложение прораба с офлайн-очередью.
