# «Объектив» — кратко

**Объектив — интеллектуальный мониторинг строительной площадки.**

На стройке есть камеры и график работ, но сверяет их человек вручную — долго, а срыв срока замечают поздно. «Объектив» делает это сам.

**Как это работает:** камеры снимают площадку → нейросеть находит технику и людей → система убирает дубли между камерами (один объект = один) → по каждому дню ставит уровень активности (работа идёт / только ресурсы / ничего / кадров нет) → сверяет с графиком и отчётом подрядчика → показывает отклонения, риск и прогноз срока — с доказательством кадрами.

Руководитель видит три вещи **раздельно**: подтверждена ли работа наблюдением, расходится ли это с отчётом подрядчика и насколько сдвигается срок. Цвет статуса зависит только от камеры. Принцип честности: система не утверждает, что работа выполнена, а фиксирует только то, что видела; непроверяемое честно помечается «не проверяется».

Руководитель видит объекты **по проблемности** (беспроблемные не мешают), план и факт, календарь, кадры, риск и прогноз срока. Отдельно — **переброска бригад**: отставание по одним работам компенсируется опережением по другим, и наверх выходит слабое звено (например, поставщик).

**Технологии:** YOLO (17 классов техники), FastAPI, PostgreSQL, React + TypeScript, Docker.

Главное: честная картина вместо иллюзии, доказательства кадрами, справедливые расчёты и статус портфеля за 30 секунд.
