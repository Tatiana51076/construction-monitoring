# План развития проекта «Объектив»

> Обязательное задание ТЗ. Коротко, реализуемо, с акцентом на уникальность.

---

## 1. Проблема

На стройке есть график и камеры, но сверяет их человек вручную — долго, а срыв срока
замечают, когда он уже случился. Главное: **отчёту подрядчика нельзя верить без
доказательства** — «заявлено 100 %» не значит «сделано».

## 2. Решение

«Объектив» автоматически сверяет кадры с камер с графиком и отчётом подрядчика и
показывает честный вердикт: **идёт ли работа по плану и можно ли верить отчёту** — с
доказательством кадрами.

## 3. Для кого

| Роль | Задача |
|---|---|
| Руководитель проекта | видеть срывы, риск, эскалировать |
| Инженер ПТО | сверять факт с планом, вести график |
| Технадзор | фиксировать исход замечаний, удержания по КС-2 |
| Прораб | один тап — фото, видеть факт и рейтинг бригад |

## 4. Чем мы уникальны

| | Стройконтроль | BIM-видеоаналитика (Buildots/Disperse/Openspace) | **«Объектив»** |
|---|---|---|---|
| Запуск | обходы, Excel | BIM/3D, 360°-камеры, лазер | **обычные камеры + фото** |
| Что меряет | «на глаз» | геометрия/прогресс | **сверка графика с фактом** |
| Ловит «заявлено 100 %, а нет» | нет | нет | **да — «ложное завершение»** |
| Без связи | нет | нет | **да — офлайн-прораб** |

5 отличий: **1)** аудит, а не прогресс (обоснование удержания по КС-2);
**2)** честность — «фиксируем, а не утверждаем», каждое замечание с кадром;
**3)** офлайн-прораб + соревнование бригад; **4)** дешёвое внедрение без BIM/лазера;
**5)** методика, а не магия (17 классов, дедупликация, правила R1–R8, вердикт объясним).

## 5. Технологии

YOLO (17 классов техники) · FastAPI (REST/JSON) · PostgreSQL (SQLite для демо) ·
React + TypeScript (дашборд) · мобильное приложение прораба (офлайн-очередь) ·
Docker.

## 6. Текущий статус (что уже работает)

- Сквозной сценарий на живых данных: фото → детекция → сверка с планом → вердикт.
- Движок сверки (правила R1–R8, уровни дня, три оси), дашборд, приложение прораба.
- Диагностика API в тех.режиме (для поддержки).
- Демо идёт не на мокапах, а на реальном API и фото.

## 7. Этапы развития

**Фаза 0 — Демо/MVP (сейчас).** Камера → нейросеть → сверка → вердикт на дашборде и в
приложении. Результат: отвечаем на вопрос жюри на живых данных.

**Фаза 1 — Пилот на 1 объекте (4–6 недель).** Реальные камеры, план-график заказчика,
калибровка зон, акты простоя, накопление датасета. Результат: первый объект под
контролем, удержания обоснованы.

**Фаза 2 — Продукт (2–3 месяца).** Портфель объектов, импорт графика (Excel/КС-2), роли,
отчёты и уведомления, жизненный цикл замечания. Результат: управление стройкой в одном окне.

**Фаза 3 — Платформа (6–12 месяцев).** Дообучение модели (арматура, двери, дефекты),
прогноз сроков, интеграция с 1С/BIM, API для партнёров. Результат: масштабируемый продукт.

## 8. Бизнес-модель (реалистично)

- **Подписка за объект (SaaS):** тариф за камеру/объект в месяц — предсказуемо и просто.
- **Старт:** пилот бесплатно → подписка, когда заказчик увидит первую обоснованную
  претензию/удержание.
- **Кто платит:** застройщики, технадзор, ПТО-отделы, банки (стройконтроль при кредитовании).
- **Дальше:** success-fee (% от обоснованных удержаний) — после доказанной ценности.

## 10. Риски и как их снимаем

| Риск | Решение |
|---|---|
| Модель знает мало классов | честный статус «не проверяется», дообучение, приложение прораба |
| Плохие ракурсы/кадры | рекомендации по установке камер (ТЗ), 1 кадр/час |
| Сопротивление подрядчиков | честность + кадры-доказательства + исход «объяснено» |
| Нет камер на объекте | приложение прораба как независимый источник факта |

## 11. Метрики успеха

- Время от кадра до вердикта (< 2 с API).
- Доля дней с подтверждением (покрытие наблюдением).
- Точность детекции и ложные срабатывания (→ дообучение).
- Число выявленных «ложных завершений» и объём обоснованных удержаний.
- Статус портфеля руководитель понимает за 30 секунд.

## 12. Итог

Камеры есть у многих, график — у всех. Никто не связывает их в **честный аудит с
доказательством**. Мы делаем это первыми — и делаем реализуемо: без дорогого железа,
без BIM, с приложением, которое работает даже без связи. Ставьте камеры, дайте график —
остальное сделаем мы.
